# fuse-deck

fuse-deck lets an agent build slide decks from [Fuse](https://github.com/elmeragroup/fuse)
components. The agent writes one typed `deck.tsx` per deck, checks it against short text rules,
and exports it to PDF, PNG, web and PowerPoint. PowerPoint files keep real title and body
placeholders, so people can edit them like any other deck.

fuse-deck is in development and not yet published to npm.
